# SEMIS / EMIS student update demo

A responsive static form prototype for updating an EMIS ID, student name, Aadhaar number, phone number, and student photo.

## Run locally

Open `index.html` in a browser. The form performs browser-side validation and photo preview only. It does not send, save, or upload data.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save. Once GitHub Pages finishes deploying, the site URL will appear in that Pages settings section.

## Important privacy note

Do not use this public demo to collect real student information. It has no database or secure submission endpoint. Aadhaar numbers and student photos require an authorized, access-controlled backend and appropriate privacy, security, and retention safeguards before real use.
